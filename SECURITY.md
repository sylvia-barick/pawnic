# Security Policy

## Supported Versions

Only the latest version of PAWnic is supported for security updates.

| Version | Supported |
| ------- | --------- |
| Main/Dev | :white_check_mark: |
| < 1.0.0  | :x: |

## Reporting a Vulnerability

We take the security of PAWnic seriously. Since it handles on-chain financial payments via the Stellar Network (buy-ins and payouts), any vulnerability affecting state validation, payout execution, or private keys is considered critical.

If you find a security vulnerability, please do NOT create a public issue. Instead, report it through one of the following channels:

* Open a private vulnerability report on GitHub (if enabled)
* Contact the maintainers directly via security email or Discord (details in repository profile)

Please include the following in your report:
1. **Description**: Detail of the potential vulnerability.
2. **Steps to Reproduce**: A minimal proof of concept (PoC) demonstrating the vulnerability.
3. **Impact**: How this vulnerability affects players, transactions, or the vault's assets.

We will acknowledge receipt of your report within 48 hours and work with you to patch the issue before making a public disclosure.
